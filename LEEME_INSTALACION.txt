CONTROL DE HORAS Y PRODUCTIVIDAD — DISEÑO POLICIAL 4.1.0

CONTENIDO
- index.html: aplicación completa.
- manifest.webmanifest: configuración de instalación como aplicación.
- sw.js: caché y actualización automática (caché v4.1).
- icon-192.png e icon-512.png: iconos de la aplicación.

PUBLICAR LA ACTUALIZACIÓN EN GITHUB PAGES
1. Descomprime este ZIP en el ordenador.
2. Abre tu repositorio de GitHub (Control-horas).
3. Entra en la carpeta donde están actualmente index.html, manifest.webmanifest y sw.js.
4. Sube y reemplaza esos tres archivos por los de esta versión. Sube también los dos iconos si deseas mantenerlos sincronizados.
5. Confirma los cambios (Commit changes).
6. Espera a que GitHub Pages termine de publicar.
7. En el móvil, abre la dirección de tu aplicación con Chrome. Recarga la página. Si no aparece el diseño nuevo, cierra la PWA y vuelve a abrirla; después espera unos segundos para que el service worker actualice la caché.
8. Si sigue apareciendo la versión anterior, abre la web en Chrome > información del sitio > almacenamiento y borra SOLO los datos de ese sitio; luego vuelve a abrir la dirección e instala/añade a pantalla de inicio otra vez. Antes de borrar datos del sitio, descarga una copia JSON desde Copias de seguridad.

DATOS Y COPIAS
- Los registros existentes usan la misma clave localStorage "horas_productividad_v1" para facilitar que se mantengan en el mismo navegador/dispositivo.
- Las tarifas personalizadas se guardan aparte.
- La publicación de una nueva versión NO realiza una copia de seguridad de los registros. Descarga la copia JSON desde la aplicación antes de borrar datos del navegador o cambiar de dispositivo.
- La aplicación no envía los datos a GitHub: los guarda localmente en el dispositivo/navegador.
