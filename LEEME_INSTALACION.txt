ANTES DE ACTUALIZAR
1. Exporta una copia de seguridad desde la aplicación actual y conserva el archivo JSON.
2. Descomprime este ZIP.
3. En GitHub abre el repositorio y selecciona Add file > Upload files.
4. Sube los seis archivos y pulsa Commit changes.
5. Espera a que GitHub Pages publique los cambios.
6. Abre la web en Chrome y recarga. Si la app instalada conserva la versión anterior, cierra y vuelve a abrirla tras actualizar la página.

IMPORTANTE
No borres los datos del navegador ni desinstales la aplicación durante la actualización. La versión conserva la clave local de registros y tarifas.
