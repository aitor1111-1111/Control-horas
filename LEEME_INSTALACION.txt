CONTROL DE HORAS Y PRODUCTIVIDAD – VERSIÓN 5.6.0

CAMBIOS DE ESTA VERSIÓN
- Se sustituyen los gráficos circulares por histogramas de barras horizontales, tanto para importes como para cantidades.
- Se añaden iconos más coloridos y diferenciados para cada tipo de servicio en el selector y en el historial.
- Se conserva el diseño compacto y adaptable a móviles.
- Se mantienen las tablas mensuales de cantidades y de importes de la versión 5.6.0.
- Se conserva el almacenamiento local de registros y tarifas de las versiones anteriores.

ARCHIVOS
Sube estos seis archivos a la raíz del repositorio GitHub Pages, sustituyendo los anteriores:
index.html
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
LEEME_INSTALACION.txt

ANTES DE ACTUALIZAR
1. Exporta una copia de seguridad desde la aplicación actual y conserva el archivo JSON.
2. Descomprime este ZIP.
3. En GitHub abre el repositorio y selecciona Add file > Upload files.
4. Sube los seis archivos y pulsa Commit changes.
5. Espera a que GitHub Pages publique los cambios.
6. Abre la aplicación en Chrome y recarga la página. La versión nueva se identifica como 5.6.0.

IMPORTANTE
No borres los datos del navegador ni desinstales la aplicación durante la actualización. La versión conserva las claves locales horas_productividad_v1 y horas_productividad_rates_v1.

- Iconos profesionales vectoriales diferenciados para los siete conceptos.
- Columna Total al extremo derecho de ambas tablas mensuales y total anual. En la tabla de cantidades, el total general suma cantidades de horas y servicios y debe interpretarse como suma de unidades registradas, no como una magnitud homogénea.
